# Matrix Calculator 

A Python-based matrix calculator built with **NumPy**. This project allows users to create matrices, perform mathematical operations and explore important concepts of linear algebra through an interactive terminal interface.

## Features

The calculator currently supports the following operations:

### Matrix Operations
- **Matrix Creation:** Create custom matrices by choosing their number of rows and columns.
- **Matrix Display:** Display the current matrix.
- **Matrix Determinant:** Calculate the determinant of a square matrix.
- **Matrix Rank:** Calculate the rank of a matrix.
- **Matrix Inverse:** Calculate the inverse of an invertible square matrix.
- **Comatrix:** Calculate and display the comatrix of a matrix.
- **Matrix Multiplication:** Multiply two compatible matrices.

### Scalar Operations

Perform mathematical operations between a matrix and a scalar:

- Multiplication
- Division
- Addition
- Subtraction
- Exponentiation

The program also provides an interactive menu to navigate between operations.

## Technologies Used

- **Python** – Main programming language.
- **NumPy** – Matrix creation, manipulation and mathematical computations.

## Project Structure

```text
Matrix-Calculator/
│
├── main.py
│
└── module/
    ├── SetMatrix.py
    └── MatrixOperation.py
```

- **main.py:** Contains the main program and the interactive menu.
- **SetMatrix.py:** Handles matrix creation, dimension selection and matrix multiplication.
- **MatrixOperation.py:** Contains the mathematical operations, including determinants, rank, inverse, comatrix and scalar operations.
